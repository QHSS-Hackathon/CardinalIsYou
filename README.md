# Cardinal Is You
The second ranked game for the second QHSS Annual Hackathon. <br/>
Collaborate with your teammates to complete a series of 8 logic puzzles, manipulate rules and propositions to your advantage. <br/> <br/>

This project is completed. <br/>
Link to Game: https://spiralking.itch.io/cardinalisyou <br/>

# Design Goals
- Allow players to intuitively grasp the game with pacing introduction of mechanics and ramping difficulty
- Create a series of 8 puzzles that is possible but challenging to complete with allocated 45 minutes for the game
- Mimic the structure of logical puzzles found in puzzle game "Baba Is You"
- Create puzzles that benefit from discussing with teammates
- Encourage players to think logically as a programmer would to improve their skills in this hackathon.

# Feature list
- Rule System
  - You/Stop/Push/Win
  - Lose
  - Open/Shut
- Nouns
  - Rules apply to nouns
  - Nouns can be converted to other nouns
- Operators
  - Is/And
- Proposition Forming
  - Move text together to form propositions right to left, up to down.
- Puzzles
  - Tutorial Puzzles (1-4)
  - Medium Puzzles (5-6)
  - Challenge Puzzles (7-8) <br/>
# Design Reflection
- Observations: During play, many got through the first half of the levels rather quickly, progress slowed in the medium puzzles, the teams that did well were the ones
  that continually tried new things and discussed with their teammates. Everyone was very focused. Some even cheered after completing a puzzle. Most teams reached solved up to
  puzzle 7, only two teams solved puzzle 8. No bugs were reported.
- Thoughts: The pacing of difficulty and mechanics was good enough to know those unfamiliar with "Baba Is You" were able to quickly solve puzzles and understand the
  premise of the game. I noticed that teams mostly used the same solutions. Designing puzzles to have multiple solutions would be an improvement, it would
  fulfill the goal of encouraging thinking like a programmer would, as few if any coding problems have one solution.
